# HVL Ramamandira Trust ERP

A comprehensive ERP system for managing the activities of HVL Ramamandira Trust.

## Features

- Choultry Booking
- Donation Management
- Donor Management
- Seva Management
- Hall Management
- Trustee Management
- Employee Management
- Financial Accounts
- Receipt Generation (PDF)
- Executive Dashboard

## Technology

- Laravel 13
- PHP 8.3
- MySQL
- AdminLTE

Version: v0.5
